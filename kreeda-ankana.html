Artificial Intelligence
GenAI-Powered Features
🤖
Smart Match Suggester
AI analyses team history, sport, skill level and available slots to suggest the best opponent teams from nearby villages.
📢
Challenge Writer
AI drafts bold, engaging challenge posts in local language (Hindi, Marathi, Telugu) from simple team inputs — no typing needed.
📊
Match Commentary
Enter the final score and AI auto-generates a vivid match summary and scorecard for the Score Wall — like a local sports reporter.
🌐
Multilingual UI
AI translates the entire app interface at runtime to the user's preferred language — making it accessible across diverse rural communities.
📅
Smart Slot Recommender
AI suggests the best available time slot based on team size, sport type, historical usage patterns, and weather (via API).
🏅
Team Profile Builder
AI generates team profile bios and village sports leaderboards from match history stored in Room DB.

Booking Conflict Prevention · Firestore Transaction
firestore.runTransaction { transaction ->
  val slotRef = db.collection("slots")
                   .document("$date-$timeSlot")
  val slot = transaction.get(slotRef)

  if (slot.getString("status") == "available") {
    transaction.update(slotRef, mapOf(
      "status" to "booked",
      "teamId" to currentTeamId,
      "sport" to selectedSport
    ))
  } else {
    throw Exception("Slot already taken! Choose another time.")
  }
}

// Challenge Board — subcollection for replies
// challenges/{id}/replies/{replyId} — real-time listener
db.collection("challenges/$challengeId/replies")
  .addSnapshotListener { snapshot, _ ->
    replies = snapshot?.toObjects(Reply::class.java)
  }

Evaluation
Success Criteria
01
Double Booking Prevention
The booking flow uses Firestore atomic transactions. If two teams simultaneously try to book the same slot, only one succeeds — the other gets an instant "Slot taken" error and is shown the next available time.
→ Firebase Firestore runTransaction
02
Challenge Board with Replies
Users can post challenges, reply to existing ones, and accept a match. Accepted challenges auto-create a booking. All updates sync in real-time via Firestore snapshot listeners — no refresh needed.
→ challenges/{id}/replies subcollection + addSnapshotListener
03
Bold and Sporty UI
The app uses Barlow Condensed for all headings (heavy condensed sports-typography), an orange-on-dark-navy palette, a grid calendar with color-coded slot states, and large score numbers — unmistakably built for sport.
→ Jetpack Compose + Custom Material You Theme + Barlow Font
